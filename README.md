# 🎓 Apex University - Campus Management Portal (Frontend)

Ye **University Campus Management System** ka complete, responsive aur interactive Frontend Web App hai. 

Isme university professors aur evaluators ko dikhane ke liye **1-Click Demo Switcher** shamil hai taake wo **Admin**, **Faculty (Teacher)**, aur **Student** teeno portals bina kisi login pareshani ke direct test kar sakein!

---

## 🚀 Quick Start (Apne Computer Par Chalane Ka Tareeqa)

1. Apne computer me folder open karein: `D:\Kotlin\UniversityCampusManagement\`
2. `index.html` file par **Double Click** karein.
3. Ye direct aapke Google Chrome / Edge browser me live open ho jayegi!

---

## 🌐 University Walo Ko Live Link Dene Ke 2 Aasan Tareeqay

### Option 1: Vercel (1 Minute Me Official `.vercel.app` Link) - *Sab Se Recommended*
1. [vercel.com](https://vercel.com) par free account banayein (ya GitHub se login karein).
2. **Add New Project** par click karein.
3. `D:\Kotlin\UniversityCampusManagement` folder ko select / drag karein.
4. **Deploy** button daba dein.
5. 30 seconds me aapko public link mil jayega:  
   👉 `https://apex-campus-portal.vercel.app`  
   *(Ye link direct university walo ko bhej dein).*

---

### Option 2: Netlify Drop (Zero Configuration - Sirf Folder Drag Karein)
1. Browser me open karein: [app.netlify.com/drop](https://app.netlify.com/drop)
2. Folder `D:\Kotlin\UniversityCampusManagement` ko browser screen par drag & drop kar dein.
3. 10 second me aapka live public URL generate ho jayega (e.g. `https://apex-campus.netlify.app`).

---

### Option 3: GitHub Pages (Free Hosting)
1. GitHub par ek new repository banayein: `university-campus-management`.
2. Folder ki tamam files upload karein.
3. Repository ki **Settings** > **Pages** me jayein aur **Branch: main** select karke Save karein.
4. Aapka link ready ho jayega: `https://<your-username>.github.io/university-campus-management/`.

## 🌟 Included Features & Portals

### 1. 🛡️ Admin Portal
* **Executive Campus Stats**: Total 4,820 Enrolled, 245 Faculty, Fee Collection Rate (92.4%), Avg Attendance (86.8%).
* **Interactive Charts (Chart.js)**: Department-wise Enrollment bar chart aur Fee Clearance ratio doughnut chart.
* **Student Directory**: Roll No, CGPA, Attendance, Fee status with Live Search & Department Filter.
* **Add Student Modal**: New student registration form with instant table update.
* **Campus Timetable**: Complete weekly routine with lecture halls and time slots.
* **Campus Circulars**: Priority-based official notice board.

### 2. 👨‍🏫 Faculty / Teacher Portal
* **Assigned Courses**: CS-311 (Design & Analysis of Algorithms), CS-401 (Advanced AI).
* **Daily Attendance Marker**: Interactive attendance sheet with 1-click **Present**, **Absent**, **Late** toggles and Save confirmation toast.
* **Classes Overview & Notice Board**.

### 3. 🎓 Student Portal (Muhammad Ali Khan - BCS-FA22-019)
* **Student KPI Cards**: CGPA (3.78 - Dean's List), Attendance (91.2%), Enrolled Credits (15 Cr).
* **Visual Performance**: Radar chart for subject-wise attendance and semester GPA growth trajectory.
* **Enrolled Courses**: Detailed course breakdown with credits, teacher name, lecture hall, and progress bars.
* **Attendance Matrix**: Total classes held, attended, missed, and final exam eligibility status.
* **Official Fee Challan Voucher**: Printable fee receipt with barcode simulation, breakups, and Print button.

### 4. ⚙️ Additional Features
* **Dark / Light Theme Toggle**
* **Mobile-Friendly Responsive Sidebar & Layout**
* **Dynamic Toast Notifications**
* **Zero Dependencies Needed**: Local machine par bina Node/Python ke bhi direct double-click se chalti hai.
